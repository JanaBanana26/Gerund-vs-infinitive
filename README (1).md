# Grammar Roadtrip USA

An interactive, browser-based ESL game for Grade 8 students to practice gerunds and to-infinitives. Travel through nine US cities by completing grammar challenges, earning XP, and collecting achievement badges.

## Play

Open `index.html` in a modern browser. There is no build step, installation, or account required. Progress saves automatically in the browser on the device being used.

## Activities

- **Multiple choice:** Choose the correct verb form and get instant feedback.
- **Fill in the gap:** Type the missing gerund or to-infinitive.
- **Verb sorting:** Drag verbs into the right category, or tap a verb and a category to sort it. Get a one-time 30 XP bonus for sorting all eight correctly.
- **Grammar pit stop:** Review common verb patterns and example sentences.

Correct answers earn 10 XP the first time each question is completed. You can revisit activities to practice without earning XP again. Use the browser's site-data controls if you want to clear saved progress and start over.

## Deploy with GitHub Pages

1. Push `index.html` to the root of your GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.

The site will be available at `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/`.

## Recommended use

Use for Grade 8 English lessons, grammar revision, learning stations, homework, individual practice, or interactive whiteboards. The responsive layout and large controls are designed for phones, tablets, and Chromebooks.
